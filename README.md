# UPI MDR Lab

A mobile-first calculator and source-led explainer for NPCI's UPI MDR framework effective 15 October 2026.

- Models standard P2M, P2PM, industry-programme and capital-market treatment
- Separates merchant acceptance cost from the consumer's ₹0 direct UPI fee
- Includes exact boundary logic, monthly volume and optional GST-on-fee estimate
- Uses only client-side code and sends no data anywhere

Primary source: [NPCI FAQ dated 15 September 2026](https://www.npci.org.in/uploads/FA_Qs_Merchant_Discount_Rate_MDR_on_Select_UPI_P2_M_Transactions_58dba1d39e.pdf)
